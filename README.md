# Inverted Pendulum — Simulation and Control

Python project for simulating an inverted pendulum. It provides physics models, plotting utilities, and example controllers.


Quick start (Poetry)
1. Install Poetry if you don't have it: `pip install poetry`.
2. Install dependencies:

   poetry install

3. Run the example simulation:

   poetry run python main.py

Quick start (venv + pip)
1. Create and activate a virtual environment (Windows cmd):

   python -m venv .venv
   .venv\Scripts\activate

2. Install dependencies with Poetry or manually if you prefer. With Poetry:

   pip install poetry
   poetry install

3. Run the example:

   python main.py

Configuration
- Edit `configs/invertedpendulum.yaml` to change simulation parameters.
